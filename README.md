## What this is

In the energy eigenstates |n⟩ of the quantum harmonic oscillator, the dimensionless position and momentum variances are

⟨ξ²⟩ₙ = ⟨π²⟩ₙ = n + ½

with ξ = (a + a†)/√2, π = (a − a†)/(i√2), [ξ, π] = i, and vacuum variance ½. Consecutive eigenstates therefore form a ladder of equally spaced rungs: the step from n to n + 1 is exactly 1 in oscillator units (ħ/mω in physical units). This repository collects that textbook fact, a family of elementary consecutive-integer identities that map onto it, a computational verification of every number quoted in the documents, and a companion experimental protocol written as a teaching and calibration exercise for a trapped-ion oscillator.

The identity a + a² + b = b² with b = a + 1 (the “ML Identity,” rediscovered by the author in 1999) is one form of a classical family:

| Form | Statement (b = a + 1) |
| --- | --- |
| F1 | a + a² + b = b² |
| F2 | b² − a² = a + b |
| F3 | ab = a² + a |
| F4 | (b − a)² = 1 |
| F5 | a² + b² = 2ab + 1 |
| F6 | b² = a² + (2a + 1) (gnomon) |
| F7 | ab = (a + ½)² − ¼, i.e. n(n+1) = (n+½)² − ¼ |
| F8 | Tₐ + T_b = b² (adjacent triangular numbers) |
| F9 | 8Tₐ + 1 = (a + b)² |
| F10 | T_b − Tₐ = b |

These are elementary algebraic identities for consecutive integers and half-integers, known classically (Nicomachus; Fibonacci’s *Liber Quadratorum*, 1225). They are not unique: every degree-≤2 identity that holds on the line b = a + 1 is a multiple of b − a − 1. The paper shows where each form appears on the ladder — for example, n(n+1) is the excess of ⟨ξ²⟩⟨π²⟩ over the Heisenberg value ¼, and, for a thermal state, it is the photon-number variance n̄(n̄+1).

Version 2 withdraws the earlier “shadow line” claim δπ = δξ + 1, which fails for every Fock state (where δπ − δξ = 0). The +1 is the step between rungs, not a constraint on a single state. A squeezed-vacuum point that can be singled out algebraically is reported as a **null result**: under standard Gaussian-channel decoherence it has no special stability. A quartic oscillator is included as a negative control, where the unit step does not hold.

Every number in the paper, supplement, and protocol is read from `results/results.json`, which `code/fvl_verify.py` writes. Pass/fail labels are computed against stated tolerances; they are not hard-coded.

## Reproducing the results and figures

Requires Python 3.10 or later, plus the packages in `requirements.txt`. There are no random elements.

```bash
python -m pip install -r requirements.txt
python code/fvl_verify.py
python code/check_results.py
python code/regen_figures.py
```

`fvl_verify.py` overwrites `results/results.json` and prints a summary of computed verdicts. `check_results.py` asserts those verdicts, including the expected **FAIL** of the withdrawn δπ = δξ + 1 claim and the null result at the algebraically singled-out squeeze parameter r\*.

To rebuild the Word documents and, if LibreOffice is installed, the PDFs:

```bash
python -m pip install python-docx
./code/run_all.sh
```

`run_all.sh` will skip the protocol rebuild unless a local copy of the v1.0 protocol source document is present. That source file is not part of this repository. The paper and supplement are generated from scratch and do not need it.

Continuous integration on this repository installs the dependencies, reruns the verification, checks the verdicts, and regenerates the figures on Python 3.10–3.13.

## Honest limitations and open items

This package is a preprint. It has not been refereed. The computations check the algebra and the numerical implementation against stated tolerances; they do not test nature. The experimental protocol is a paper protocol, not a completed measurement.

A few items still need the author’s attention, and this repository does **not** assert them:

- A 99.9% ground-state occupation figure associated with Schmidt-Kaler et al. in ⁴⁰Ca⁺ is flagged in the documents as “to be verified.” The citation year in the inherited source did not match the reference list, and the claim has not been independently checked here.
- Protocol reference [10] (PRX Quantum 6, 2025, joint-parity tomography) has no authors listed in the inherited draft. Those authors still need to be added; they are not supplied here.
- The list of laboratories described as having demonstrated capability was not independently verified, and those laboratories were not contacted.

The full correction history, including withdrawn claims and numerical fixes, is in [`CHANGELOG.md`](CHANGELOG.md).
